# Flagcall — Brand Guide

**Working tagline (proposed):** Flag the rule. Settle the argument.

## The mark
A football referee's penalty flag, thrown: yellow cloth, white weighted cuff and tail, with motion streaks. The call, made.

## Type
Headings and numbers: SF Pro Rounded (bold). Body: SF Pro (system). The wordmark SVGs reference these fonts by name, so **convert the text to outlines in a vector editor before using a wordmark in print or on the web**, otherwise it will fall back to another font on machines without them.

## Voice
Short, direct, fair. Give the ruling first, then the rule number. No hedging when the rule is clear; say plainly when it is not.

## Name check
On 2026-10-14 a search of the US App Store found no app titled exactly "Flagcall". This is not a trademark search and not a guarantee the name will be accepted: check App Store Connect name availability and run a USPTO search before committing. Alternates considered: Rulecall, Refcall.

## Icon rules
- Keep the mark inside the central ~80% of the icon canvas.
- No text on the icon.
- Check the icon at 60×60 pt and in dark, tinted and clear iOS appearances before submission.
